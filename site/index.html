Myanmar text in, readable English-letter slug out. Runs entirely in this page.

→

Hear it

This uses the browser's built-in speechSynthesis, which reads with the voices your device has installed. Voices marked local work offline; network voices send the text to a speech server and need internet. Most devices have no Burmese voice. If yours has none, the Myanmar button is disabled, but an English voice can still read the romanized slug.

Voice on this deviceLanguageWorks

Use it

npm install myanglish

import { slugify } from 'myanglish'
slugify('မြန်မာ')   // 'myan-ma'
